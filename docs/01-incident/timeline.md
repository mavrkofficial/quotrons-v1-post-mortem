# Incident timeline and containment transactions

All timestamps below are derived from Robinhood Chain block timestamps. Central
Time was UTC-5 on August 12–13, 2026.

## August 12, 2026 (America/Chicago)

### 7:51:22 PM — representative exploit transaction

Transaction
[`0xe35c…bd8c`](https://robinhoodchain.blockscout.com/tx/0xe35ce85a413415ab268b5e7e7ce822066072de5117ebf081d2ca4357d22cbd8c)
at block `34,973,603` shows the observed operator calling the exploit contract
during a stale-approval terminal transfer. This transaction is a representative
example, not the complete incident set.

### 7:59:58 PM — observed exploit runtime codehash banned

Transaction
[`0x179d…5985`](https://robinhoodchain.blockscout.com/tx/0x179d4dd6024bbf854b77feac2137fa26ce6decc302c5dbf01737707d1c095985)
at block `34,978,749` called V1
`banVenueCodehash(bytes32,bool)` for runtime codehash:

`0x849542ca8df7205f2117bfa1a8556e57c3a2a71e7b806e07597a33a5f8835723`

This blocked the observed exploit contract code path. It did not erase stale
approvals or repair V1's approval lifecycle.

### 8:09:32 PM — ten registered canonical pools stopped

Transaction
[`0xe250…d7f6`](https://robinhoodchain.blockscout.com/tx/0xe250bed652711301eafd807d537dd44b5356482e8333553af2421c4eddccd7f6)
at block `34,984,482` redirected V1's authorized hook to the dead address.

All ten hook-registered canonical pools recorded zero swaps after this block.
This block is the liquid migration cutoff.

The transaction was not a global token pause. V1 retained a PoolManager
authorization design that allowed separately created pools to trade. The
external-pool ledger records `562` post-cutoff swap events across nine indexed
external pools.

### After containment — official frontend actions disabled

The official interface disabled buy, sell, hardwire, and transfer actions and
displayed incident messaging. This was an operational control, not an on-chain
transaction, and could not prevent interaction through third-party interfaces.

## August 13, 2026

### 3:43:20–3:46:14 AM — V1 burn and LP pots preserved

Ten keeper-authorized `sweepPots` transactions moved the accumulated V1 burn
and LP pots to the published keeper wallet for V2 redeployment. Each successful
transaction, block, sender, destination, and timestamp is recorded in
`data/transactions/mitigation.csv`.

### 6:00:00 AM — announced hardwired ownership cutoff

Block `35,337,540`, hash
`0x85a3668228eb45a92d4b41e042ba15058978924fe279808004ff891216250eb4`,
is the last block at or before the announced hardwired terminal trading cutoff.

Only the `2,001` terminals already hardwired at liquid cutoff block
`34,984,482` are eligible for V2 lit copies. Their recipients follow V1 NFT
ownership through block `35,337,540`.

## Canonical source

The transaction table is generated by
`scripts/build-mitigation-ledger.mjs`. The script fetches each transaction,
receipt, and block directly from Robinhood Chain, verifies its destination, and
writes `data/transactions/mitigation.csv`.
